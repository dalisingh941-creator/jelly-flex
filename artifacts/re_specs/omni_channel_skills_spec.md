# Inbuilt Social Media Agent Skills — Clean-Room Harvesting Specification
**Framework:** REA (Reverse Engineer Anything) 5-Stage Clean-Room Methodology  
**Target:** social-media-skills/skills, sergebulaev/*, Jakeschincariol/*, ScrapeCreators/*, Panniantong/Agent-Reach, mvanhorn/last30days-skill  

---

### Harvested Skill Suites
1. **Foundation:**
   - `brand-profile`: Brand identity, audience persona, core messaging pillars, anti-slop guidelines.
   - `voice-builder`: Tone consistency, cadence, punchy sentence rhythm, platform vocabulary.
   - `hook-writer`: 0-3 second curiosity gaps, pattern interrupts, and tension builders.
   - `content-calendar`: Scheduling cadences, content pillars, seasonal planning.

2. **Instagram Suite (`instagram-suite`):**
   - Reels scriptwriting (0-3s hook, 5s retention beats, audio cues).
   - 10-slide carousel architecture (hook slide, value progression, punchline, CTA).
   - Instagram keyword SEO (searchable captions, hashtag clusters, alt text).
   - Stories sequence flow (interactive polls, question boxes, link stickers).

3. **YouTube Suite (`youtube-suite`):**
   - Long-form narrative scripting (retention curves, visual B-roll cues).
   - YouTube Shorts retention engine.
   - CTR title variations + thumbnail contrast briefs.
   - Timestamped chapters and SEO-optimized descriptions.

4. **TikTok Suite (`tiktok-suite`):**
   - High-velocity pattern-interrupt hooks.
   - TikTok Photo Mode carousel formatting.
   - Trending sound matching and viral pacing.

5. **X / Twitter Suite (`x-twitter-suite`):**
   - 280-character high-signal single posts.
   - High-tension thread drafting with clean readability.
   - Grok-style live timeline reply flywheel.

6. **LinkedIn Suite (`linkedin-suite`):**
   - "See-more" fold hook mechanics (first 2 lines).
   - B2B document carousel slide briefs.
   - Thought leadership essays with operational metrics.
   - Strategic commenting flywheel.

7. **Threads & Facebook Suite (`threads-facebook-suite`):**
   - Meta Threads conversation starters and debate prompts.
   - Facebook Group community questions and organic discussions.

8. **Pinterest & Reddit Suite (`pinterest-reddit-suite`):**
   - Pinterest visual keyword SEO and 2:3 vertical pin briefs.
   - Reddit authentic value-first contributions adhering strictly to subreddit rules.

9. **Research & Outlier Mining Suite (`research-outlier-miner`):**
   - Outlier post detection, viral velocity calculation.
   - Audience comment mining for recurring pain points.
   - 30-day viral trend synthesis across niches.

10. **Telegram & Discord Suite (`telegram-discord-suite`):**
    - Broadcast channel announcements, rich markdown formatting.
    - Webhook automated bridge notifications.
