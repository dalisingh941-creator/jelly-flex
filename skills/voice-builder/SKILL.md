# Voice Builder Skill

## Purpose
Governs the cadence, syntax length variation, vocabulary selection, and punctuation style to create human-sounding, captivating copy.

## Execution Rules
1. **Cadence Variation**: Alternate between punchy 3-word sentences and fluid 14-word explanatory lines. Avoid monotonous sentence lengths.
2. **First-Person Authority**: Write from personal conviction, empirical testing, or clean-room engineering perspectives.
3. **Scanability**: Utilize clean double-line breaks, high-contrast bullet points, and minimalist section dividers.
4. **Platform Vocabulary**: Use native terminology (e.g., "See More" on LinkedIn, "Reels audio" on Instagram, "Subreddit rules" on Reddit).
